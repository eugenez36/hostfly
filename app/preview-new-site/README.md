# Превью нового дизайна hostfly.by

Статическое превью, собранное по Figma-выгрузке из `app/new-design/`
(UI-кит + 7 листов `final-theme`). Открывается локально, без сборки и сервера —
достаточно открыть `index.html` в браузере.

Точка входа для обхода всех страниц — чёрная полоса «Превью нового дизайна»
сверху, она есть на каждой странице.

---

## Важное про связь с каталогом `ftp/`

Скачанная тема `ftp/public/templates/nexus/` — это **сток WHMCS 9.0**
(`theme.yaml`: `description: "The Default Theme for WHMCS 9.0"`, автор WHMCS Limited,
Bootstrap 4.5.3 + jQuery 1.12.4). Правок под Hostfly в ней нет, и покрывает она
**личный кабинет** (my.hostfly.by): счёта, тикеты, услуги, домены клиента.

Figma-макеты же описывают **публичный сайт** hostfly.by: главная, домены,
хостинг, SSL, конструкторы, партнёрская программа, инфо-страницы. Ни одной
страницы личного кабинета в макетах нет — «Служебные страницы» это «Кто мы»,
«Контакты», «Договоры», «Дата-центр», «Защита от DDoS», а не логин с регистрацией.

Поэтому превью собрано как **публичный сайт по макетам**, а от nexus взята
организация файлов (`css/`, `js/`, `includes/`, `store/`, `error/`) — чтобы
вёрстку можно было потом разложить по WHMCS-шаблонам без переделки структуры.

## Структура

```
preview-new-site/
├── index.html                    Главная (все 7 секций макета)
├── ui-kit.html                   Дизайн-система: цвета, типографика, все компоненты и состояния
├── css/
│   ├── tokens.css                CSS-переменные: цвета, шрифты, размеры, радиусы, сетка
│   ├── base.css                  Сброс, типографика, контейнеры, утилиты
│   ├── components.css            Кнопки, поля, табы, бейджи, карточки, аккордеон, таблицы
│   └── layout.css                Шапка, футер, хлебные крошки, hero-блоки
├── js/
│   ├── layout.js                 Единый источник шапки/футера/превью-навигации
│   ├── theme.js                  Аккордеон, табы, слайдер, корзина доменов, переключатели
│   └── build-includes.js         Dev-скрипт: рендерит includes/*.html из layout.js
├── includes/
│   ├── header.html               Готовая разметка шапки (справочно, для переноса в .tpl)
│   └── footer.html               Готовая разметка футера
├── domains/
│   ├── register.html             Регистрация доменов: поиск, зоны, преимущества, FAQ
│   ├── search-results.html       Результаты подбора: рекомендации, список, корзина, пагинация
│   └── transfer.html             Перенос домена: шаги, форма заявки, FAQ
├── store/
│   ├── hosting.html              Хостинг сайтов: hero, тарифы с пересчётом, преимущества, карусель
│   └── ssl.html                  SSL-сертификаты: тарифы DV/EV, промо, FAQ
├── info/
│   ├── news.html                 Новости и акции: фильтры-чипы, сетка карточек, пагинация, блог
│   └── contacts.html             Контакты: адрес, телефоны, карта, форма, реквизиты, документы
├── affiliates/
│   └── index.html                Партнёрская программа: уровни, статистика, заявка
└── error/
    └── 404.html                  Страница не найдена
```

Шапка и футер не дублируются по файлам: их рендерит `js/layout.js` в
контейнеры `<header data-layout="header">` и `<footer data-layout="footer">`.
Меняете меню — правите один массив `MENU` в `layout.js`. Файлы `includes/*.html`
генерируются из него командой:

```
node js/build-includes.js
```

## Соответствие шаблонам nexus

Где у страницы превью есть прямой аналог в WHMCS — он указан. Прочерк означает,
что в WHMCS такой страницы нет и её придётся отдавать отдельным шаблоном
(или страницей CMS).

| Страница превью | Шаблон в `ftp/public/templates/nexus/` |
|---|---|
| `index.html` | `homepage.tpl` (в стоке — плитка групп продуктов, наполнение полностью меняется) |
| `includes/header.html` | `header.html` → `header.tpl` |
| `includes/footer.html` | `footer.html` → `footer.tpl` |
| `domains/register.html` | `store/` + `domainchecker` (в стоке: `bulkdomainmanagement.tpl`, `domain-pricing.tpl`) |
| `domains/search-results.html` | результаты `domainchecker` + `clientareadomains.tpl`, корзина — `store/dynamic/` |
| `domains/transfer.html` | `clientareadomaingetepp.tpl`, `clientareadomainregisterns.tpl` |
| `store/hosting.html` | `store/` (карточки тарифов), `clientareaproductdetails.tpl` |
| `store/ssl.html` | `store/ssl/`, `configuressl-stepone.tpl`, `managessl.tpl` |
| `info/news.html` | `announcements.tpl`, `viewannouncement.tpl` |
| `info/contacts.html` | `contact.tpl`, документы — `downloads.tpl`, `downloadscat.tpl` |
| `affiliates/index.html` | `affiliates.tpl`, `affiliatessignup.tpl` |
| `error/404.html` | `error/` (в стоке 5 файлов), `access-denied.tpl` |
| — | `login.tpl`, `clientregister.tpl`, `clientareahome.tpl`, `viewinvoice.tpl`, `viewticket.tpl` и остальной личный кабинет: **в макетах не нарисованы** |

Стили в nexus лежат в `sass/` (30 файлов) и компилируются в `css/`. Если тему
будут переводить на новый дизайн — править нужно sass, иначе сборка перезатрёт
изменения. `css/` из этого превью написан независимо от Bootstrap: подключать
его к nexus стоит либо вместо бутстрапа, либо как отдельную тему.

## Дизайн-токены

Все значения сняты с UI-кита и лежат в `css/tokens.css`.

**Цвета.** Neutral: `#000000` (кнопка), `#333333` (текст), `#666666` (body),
`#999999` (элементы), `#D3D3D3` (границы), `#DEDEDE`, `#EDEDED`, `#F7F7F7`, `#FFFFFF`.
Brand: `#0027EA` primary, `#F2F7FD` secondary. Статусы: `#DB3032`, `#FFF1A1`,
`#117A24`, `#00946A`, `#C530E7` и семь светлых оттенков для бейджей и подложек.

**Логотип** — не из брендовой палитры: тёмно-синий `#181344` со градиентным
акцентом `#8C31E8 → #A86DF3` на хвосте «y» и точке. Фавикон — фиолетовый `#320A89`.

**Типографика.** H1 86/84 Medium · H2 40/48 −3% · H3 32/38 · H4 24/32 −2% ·
H5 20/28 Bold · H6 16/24 Bold · Body L 16/24 · Body M 14/22 −3%.

**Размеры контролов.** Кнопки: L 74, M 56, S 36, XS 32, иконочные 48 и 32.
Поля: 56, поиск домена 82, второстепенный поиск 52. Табы 42 (мобильные 36).
Бейджи, чипы, чекбоксы и радио — 24.

**Сетка.** Замеры по листу «главная + Домены»: viewport 1920, контентный
контейнер ≈1460px, контейнер шапки и футера шире — ≈1810px.

## Известные расхождения с макетом

* **Шрифты.** В макете NT Somic (заголовки) + Inter (текст). Файлов шрифтов в
  выгрузке нет, поэтому подключён системный фолбэк: начертания отличаются,
  метрики (кегль, интерлиньяж, трекинг) выставлены по кит-спецификации.
  Как только появятся `.woff2` — достаточно добавить `@font-face` и токены
  `--font-display` / `--font-text` заработают как задумано.
* **Иллюстрации.** Все картинки в макетах — растровые line-art в PNG. В превью
  вместо них inline-SVG-заглушки в той же стилистике (синее пятно + контурный
  рисунок). Логотипы клиентов и платёжных систем — текстовые плашки.
* **Контент.** Тексты взяты из макетов; там, где в макете стоял рыбный текст
  или дубли (например, три одинаковые новости), дописаны правдоподобные
  заглушки, чтобы страницы читались как настоящие.
* **Мобильные версии** свёрстаны по логике десктопа и мобильных артбордов кита,
  но пиксельно с мобильными макетами не сверялись — мобильные артборды в
  выгрузке узкие (~380px по ширине картинки) и читаются хуже десктопных.
