### Типографика
- **NT Somic** — основной дисплейный/заголовочный шрифт (weights 400/500/600/700).
- **Inter** — интерфейсный/текстовый (400/500).
- **Unbounded** — акцентный дисплейный (крупные цифры/спецэлементы, ~36px w500).

|---|---|---|

### Скругления
`16px` (карточки, осн.) · `8px` · `6px` · `32px` (крупные пилюли/кнопки) · `500px` (полностью круглые: аватары, иконки-стрелки).

### Тени / прочее
Тени очень сдержанные (мягкий drop-shadow ~a0.15); основной приём разделения — **тонкие серые линии** и **цветные подложки-блобы**, а не тени. Стиль иллюстраций — монолинейные скетчи + голубые/сиреневые blob-акценты.

### Кнопки (паттерны)
- **Primary:** чёрная заливка `#000`, белый текст, скругление ~8px («Оставить заявку», «Посмотреть тарифы», «Перейти к услугам»).
- **Accent:** синяя `#0027EA` («Проверить домен» — на голубой подложке).
- **Ghost/outline:** тонкая рамка («Стать клиентом»).
- **Icon-button:** круглая со стрелкой → (офферы, карусели).

### Сетка
Контейнер ~1710px по центру при ширине 1920 (боковые поля ~105px). Секции разделены тонкими линиями и крупными вертикальными отступами. Мобайл — 375px, одноколоночный стек.

## 4. Что переиспользуем для редизайна ЛК (тема WHMCS)

Эти элементы дизайн-языка нужно перенести в тему кабинета для единого вида с сайтом:
- **Палитра:** синий #0027EA + жёлтый #FFD900 + нейтрали; голубые/сиреневые подложки для акцентных блоков.
- **Шрифты:** NT Somic (заголовки) + Inter (интерфейс). ⚠️ Нужны файлы шрифтов и лицензия (NT Somic и Unbounded — не системные; для WHMCS-темы подключать self-hosted).
- **Компоненты, прямо переносимые в ЛК:** хедер/футер (единые с сайтом), продуктовые карточки → карточки услуг, таб-переключатели, аккордеон FAQ → база знаний/тикеты, поле поиска домена, бейджи-теги, круглые icon-кнопки, стиль таблиц/чипов характеристик.
- **Кнопки/скругления/сетка** — те же токены (16px карточки, чёрная primary, 8px кнопки).
- **Иллюстрации** — монолинейный стиль + blob-акценты (задать для пустых состояний ЛК: нет услуг/доменов/тикетов).

## 5. Наблюдения и вопросы по макету

1. **Готова только клиентская витрина сайта, не ЛК.** Экранов личного кабинета в этом файле нет — их дизайн ещё предстоит сделать (кем — вопрос к заказчику из аудита ЛК).
2. **Шрифты NT Somic / Unbounded — платные/некастомные.** Нужны исходные файлы и права на веб-использование для темы WHMCS.
3. **Единый хедер/футер** сайта и кабинета — желательно согласовать, чтобы переход сайт→ЛК был бесшовным (сейчас у ЛК свой старый хедер из WHMCS).
4. **FAQ на сайте ссылается на `my.hostfly.by`** — подтверждает, что кабинет — часть единого пути пользователя; дизайн-язык должен совпадать.
5. В файле десятки других страниц (Хостинг, VPS, Битрикс, 1С, SSL, Конструкторы, Блог, Договоры, Партнёрка) — если редизайн-скоуп включает и сайт, объём кратно больше; для ЛК это референс-библиотека.
