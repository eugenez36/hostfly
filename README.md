# hostfly

Рабочий репозиторий по проекту **Hostfly** — редизайн маркетингового сайта `hostfly.by`
и личного кабинета WHMCS `my.hostfly.by`.

Рабочие соглашения, разбор контуров и подводные камни — в [`CLAUDE.md`](CLAUDE.md).

## Два контура проекта

Это **два разных продукта**, между которыми почти нет пересечения (подробно —
[`docs/gap-analysis-new-design-vs-nexus.md`](docs/gap-analysis-new-design-vs-nexus.md)):

| Контур | Что это | Где в репозитории |
|---|---|---|
| Маркетинговый сайт `hostfly.by` | Выгрузка Figma-дизайна: лендинги услуг, домены, блог, инфо-страницы | `app/new-design/` |
| Личный кабинет | Тема WHMCS, с которой ведётся работа | `ftp/public/templates/nexus/` |

Тем в репозитории две, и различать их обязательно:

| Тема | Где работает | Роль |
|---|---|---|
| `nexus` | **dev**, `mydev.hostfly.by` | Рабочая. Сток WHMCS 9.0 (Bootstrap 4.5.3), редизайн делается на ней |
| `ais` | **прод**, `my.hostfly.by` | Тема прода, клон Six на Bootstrap 3. Референс состава экранов, её не правим |

Кабинет на dev перевели на `nexus` 12.08.2026 — до этого там работала `ais`, и старые
записи в документации об этом не знали. Как проверить, что активно сейчас, — в
[`CLAUDE.md`](CLAUDE.md).

## Структура

В репозитории хранятся только тема, документация, описание и источник UI-кита.
Тяжёлые артефакты — выгрузки Figma, скриншоты аудита, превью и эталонные выгрузки —
остаются в Figma и локально, вне git (см. [`.gitignore`](.gitignore)).

```
ftp/public/templates/nexus/ рабочая тема WHMCS на dev (.tpl, scss, js, ассеты)
ftp/public/templates/ais/   тема прода, референс состава экранов

ui-kit/                     источник UI-кита, снятый с Figma-выгрузки
```

## UI-кит нового дизайна

Кит снят с Figma-выгрузки и перенесён в сборку темы `nexus`:

| Где | Что |
|---|---|
| `ui-kit/` | Источник: `tokens.css`, `base.css`, `components.css`, `theme.js` |
| `nexus/_dev/scss/hf-kit/` | Перенос в сборку темы: 15 партиалов |
| `nexus/js/hf-kit.js` | Поведение: аккордеон, табы, слайдер |
| `nexus/_dev/hf-kit-preview.html` | Демо всех компонентов внутри темы |

Брендинг кабинета разложен на три слоя, каждый со своей зоной ответственности:

| Файл | Что в нём |
|---|---|
| `nexus/css/custom.css` | Палитра: значения штатных токенов темы. Сток подключает этот файл сам |
| `nexus/css/hf-theme.css` | Шрифты, высоты контролов, сетка, тени, подложки статусов, оверрайды компонентов |
| `nexus/css/hf-kit.css` | UI-кит целиком, изолирован под `.hf-kit` |

Стоковые `sass/*` и `theme.min.css` не трогаем — обновление темы их перезапишет.

**Всё, кроме токенов, изолировано под классом `.hf-kit`.** Причина: имена `card`, `plan`,
`promo`, `feature`, `tld` уже заняты в шаблонах кабинета, а Bootstrap занимает `.btn`,
`.badge`, `.pagination`, `.tabs`, `.input`. Без обёртки кит переоформил бы существующие
страницы. Применение:

```html
<div class="hf-kit"> … разметка из превью работает без изменений … </div>
```

Кит подключён в `nexus/includes/head.tpl` вместе с `hf-theme.css` — это единственная
правка стокового шаблона.

Не перенесено из кита: листы `Icons` и `Logo` (иконки в превью лежат инлайновыми SVG,
логотип есть только как цвета в токенах). Шрифтов в выгрузке нет: в макете NT Somic
(variable, `NTSomic-VF.ttf`) + Inter, поэтому в токенах пока системный фолбэк.

## Что НЕ версионируется

Локальная папка `ftp/` — это слепок **dev-сервера** WHMCS (~655 МБ), синкается по FTP
и целиком в git не входит. Из неё отслеживаются только две темы:
`ftp/public/templates/nexus/` и `ftp/public/templates/ais/`.

Важно: это **не продакшен**. Подробно — в [`CLAUDE.md`](CLAUDE.md#контуры-dev-и-прод).

Также в [`.gitignore`](.gitignore): `creds.md` (доступы), `.idea/`, дампы `*.sql`,
архивы `*.zip`, логи.

Репозиторий публичный, поэтому дополнительно исключены:

- `app/clientarea-audit/html/29-dnsmanager.html` — дамп страницы почти целиком состоит
  из инлайн-исходника коммерческого модуля ModulesGarden DNS Manager (151 КБ), он лицензионный
  и не под редистрибуцию. Структурный дамп `data/29-dnsmanager.json` и скриншот остались.
- `app/ЭСТИМАЦИЯ-редизайн-ЛК.md`, `app/ДЕМО-КП-hostfly-ЛК.html` — коммерческие документы
  (трудозатраты, КП).

В аудите кабинета номер телефона тестового аккаунта заменён на `+375XXXXXXXXX` —
и в HTML-дампе `08-details.html`, и на скриншоте `08-details.png`.
Аккаунт в аудите тестовый («Евгений Тест»), страница личных данных была закрыта SMS-верификацией.

```bash
git clone git@github.com:eugenez36/hostfly.git
```

## Работа с темой

Брендовый слой рабочей темы `nexus` — dart-sass, из `ftp/public/templates/nexus/_dev/`:

```bash
cd ftp/public/templates/nexus/_dev
npm ci
npm run build      # scss/hf-kit.scss и scss/hf-theme.scss -> ../css/
```

Собирается только наш слой; стоковый `sass/theme.scss` идёт тулчейном WHMCS и не пересобирается.
CSS не минифицируется намеренно: тема в git — зеркало сервера, читаемый дифф важнее размера.

Тема прода `ais` собирается своим старым gulp (`gulp-sass 4`, libsass, только `@import`)
и в текущей работе не пересобирается: `node-sass@4` под Node 20 всё равно не соберётся.

Деплой — синк по FTP на dev (см. `creds.md`, вне репозитория).
